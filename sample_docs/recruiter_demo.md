# RAG 工程演示文档

## 文档入库

文档进入知识库后，会先保存原文件并计算 SHA-256 指纹，再经过解析、Markdown 标题切分、递归字符切分、Embedding 和 Chroma 入库。每个阶段都会记录状态，失败文件会保留原文件，便于重试。

## 混合检索

Dense 检索根据语义相似度寻找内容，适合处理同义表达。BM25 检索根据关键词、编号和专有名词匹配内容。系统使用 Reciprocal Rank Fusion，也就是 RRF，将两路排名合并，减少单一检索方式的偏差。

## 可观测问答

问答响应会返回来源文件、document_id、chunk_index、score、检索策略和阶段耗时。用户可以在检索调试页面核对来源，也可以按 document_id 或文件名限制检索范围。

## 失败恢复

批量上传允许单个文件失败而不影响其他文件。Chroma 写入失败时会执行补偿清理，SQLite 会保存失败阶段和错误摘要。成功上传的文档支持删除和重新索引。
