# 数据与版权边界

- `app/`、`scripts/`、`tests/` 和项目文档按仓库 `LICENSE` 发布。
- `sample_docs/company_handbook.md` 是为本项目生成的示例资料。
- `eval_data/ai_agents_in_depth_eval_dataset.json` 是围绕用户本地 PDF 整理的问题、标准答案和章节标注；它不是原 PDF 的替代品，也不应被表述为原作者全文。
- 用户自己的 PDF、MinerU 返回的 Markdown、图片和解析结果不提交到仓库，除非已经确认拥有再分发权。
- 评估输出只提交脱敏后的聚合指标和少量人工核对示例，不提交 API Key、整份原文或未经授权的完整回答。
- 使用第三方 PDF 或 MinerU 输出时，应分别遵守原始资料、模型服务和解析服务的条款。
